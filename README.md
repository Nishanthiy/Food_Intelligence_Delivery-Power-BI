# Swiggy Food Delivery Intelligence Dashboard

## Project Description

The **Swiggy Food Delivery Intelligence Dashboard** is an interactive data analytics project developed using Microsoft Power BI to analyze restaurant performance, customer preferences, cuisine popularity, delivery efficiency, and city-wise business performance.

The project transforms food delivery data into meaningful business insights through interactive visualizations, KPIs, charts, and filters. It helps understand restaurant ratings, average delivery time, SLA compliance, customer reviews, cuisine trends, and cost comparisons across different cities.

Using Power BI, Power Query, and DAX, the dashboard provides a comprehensive view of food delivery operations and supports data-driven business decision-making.

## Key Features

- City-wise restaurant performance analysis.
- Average restaurant rating analysis.
- Delivery time and SLA compliance monitoring.
- Monthly delivery time trend analysis.
- Top 10 most-reviewed cuisines.
- Cuisine popularity analysis.
- Restaurant cost and rating comparison.
- Interactive filters for city and traffic level.

## Project Objective

To analyze food delivery business performance, identify customer preferences, evaluate delivery efficiency, and generate actionable insights that can help improve restaurant services and customer satisfaction.

## Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- SQL

## Expected Outcome

An interactive Power BI dashboard that converts raw food delivery data into meaningful visual insights, helping businesses understand performance trends, customer satisfaction, and operational efficiency.
